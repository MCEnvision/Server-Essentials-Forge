Security design consequences: construct URLs from validated typed operator configuration; never accept arbitrary player-controlled JDBC strings, factories, plugin class names or driver properties. Explicitly set `allowLocalInfile=false` because the connector guide documents its default as true. Use `sslMode=verify-full` for remote SQL and tested trust material, never a trust-all fallback; validate property names locally because unknown connector options may be ignored. Bound packets, columns, connect/read/query timeouts and pool size. Use least-privilege schema accounts; read-only connection hints are not an authorization boundary. Restrict local SQLite paths and native extraction directories, disable unnecessary extension loading, and do not open an uploaded or arbitrary untrusted database as authority state.

### Remaining gates, without invented readiness

All four selected artifact URLs, versions, byte counts, SHA256 and SHA512 values are settled. Hashing establishes exact retrieved content, not signer authenticity. Detached-signature verification against independently trusted maintainer keys was not performed. Full bundled dependency/license inventories, transitive version locks, SBOM/advisory scan and classloader/native extraction behavior are implementation readiness gates. Neither database binary was executed, so host library availability, initialization, TLS, JDBC handshake, schema migrations, transactions, recovery, backups, purges and performance remain unproven. The selected supported fixture families are8.4 and11.4; do not silently promise every older or future MySQL-compatible server because the connector's broad compatibility statement is broader than SEF's tested SQL contract.
