# Activity History and Compatibility Scope

Source role: owner_request. Decisions observed September 24, 2026.

The approved addition is comprehensive original Forge-native activity history using CoreProtect as a functional reference, including the later approved inspection, query, preview, rollback, restore and undo workflows. It is not a Bukkit plugin dependency. Capture server-observable activity and actual changes, including natural and machine causes, with testable attribution and honest completeness. Opaque third-party internals or unavailable hooks cannot be claimed captured without evidence.

Different backend modpacks are supported when the running client is compatible with the destination under a validated relation. Refuse unknown or incompatible transfers before switching and explain the reason. Arbitrary pack switching requires client changes and is not a separate launcher or client project in this scope.

Economy and custom interface exclusions remain binding. DEC-008 through DEC-017 and the expanded scope record resolve audit functionality, content, retention, storage, presentation, capacity and RTP behavior.
